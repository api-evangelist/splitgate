# Splitgate (1047 Games)

> Splitgate is the free-to-play sci-fi arena first-person shooter franchise from 1047 Games — the studio founded at Stanford in 2017 that shipped Splitgate (2019), Splitgate 2 (June 2025) and, after a rebuild, SPLITGATE: Arena Reloaded (December 2025). 1047 Games publishes one small public API: the Third-Party API, a read-only OpenAPI 3.0.1 contract for player search, statistics, competitive ranks, match history and match detail, intended for community stat trackers, leaderboard sites and esports tooling.

Generated by the API Evangelist enrichment pipeline on 2026-08-05. Method: generated — no llms.txt is published by the provider (/llms.txt returns 404 on splitgate.com, splitgate2.com and 1047games.com).

## APIs

- [1047 Games Third-Party API](https://1047games.github.io/sdk-api/): Five read-only GET operations over `https://api.1047games.com` — searchPlayers, getPlayerStats, getPlayerRanks, getPlayerMatches, getMatchDetails. Bearer JWT required. Cursor pagination via an opaque `anchor`.

## Conventions

- Auth: HTTP bearer, `bearerFormat: jwt`, applied globally. The contract does not document how a third party obtains a token.
- Pagination: cursor. Request `limit` (default 25, max 100) and `anchor`; response returns `items`, `nextPageAnchor`, `totalItemCount`. Anchors are valid only within one query.
- Errors: NOT RFC 9457. A custom `application/json` envelope — `reason`, `message`, `domain` (Players|Matches), `metadata` — plus a discriminated `error.status` drawn from the canonical gRPC status names.
- Rate limits: no published numbers. Quota exhaustion is modeled in-band as `error.status = ResourceExhausted` with `QuotaViolation[]`; no 429 response is declared in the contract.
- Idempotency: not applicable — the API is entirely read-only.
- Versioning: `/v1` path prefix; game titles are a path segment (`/v1/game/splitgate2/...`). `info.version` has never moved off 1.0.0.

## Caveats for agents

- The declared production host `api.1047games.com` did NOT resolve on 2026-08-05 — its CNAME target `api-third-party-prod.maverick-global.prod.1047games.com` returns NXDOMAIN. Do not assume the endpoint is live.
- Paths are scoped to `splitgate2`, the title that was relaunched as SPLITGATE: Arena Reloaded in December 2025.
- There is no MCP server, no GraphQL endpoint, no webhook or event surface, no A2A agent card, no `/.well-known/` documents, no status page and no first-party SDK.
